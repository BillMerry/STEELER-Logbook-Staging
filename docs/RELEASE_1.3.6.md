# STEELER Logbook 1.3.6

Promotes the user-tested 1.3.6-rc2 to Live with production logo, app name and cloud configuration retained.

Home filters now combine category, year, month, origin, destination and status. Refill History and Consecutive Nights on Board keep their column headings visible while scrolling, with dates linking to the relevant records. Compact arrows in the Plan heading and Log toolbar, heading/toolbar swipes and guarded keyboard arrows browse passages in Home filter order.

Settings fuel calculations reuse timestamp conversions, substantially reducing repeated work with large histories. No data migration or cloud configuration changes.

Validation: DOM and Chromium regression suites, asset checks, and a 1.3.5-to-1.3.6 service-worker update/offline persistence test.
