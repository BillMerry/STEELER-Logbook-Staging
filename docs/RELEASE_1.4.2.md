# STEELER Logbook 1.4.2

The Current Passage button now explicitly uses the app text colour, preventing iPad Safari from colouring the non-current leg blue. The current leg remains bold.

Successful sync now refreshes the last observed cloud time and device alongside the synced metadata, so the upper status panel agrees with the current cloud-copy preview.

These are display fixes. No sync transfer, cloud service, data format or logbook records are changed. The earlier intermittent service error is not claimed fixed by this patch.
