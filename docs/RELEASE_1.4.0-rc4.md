# 1.4.0-rc4

Manual log entry and edit dialogues now include optional wind direction, Beaufort force (0–12) and Douglas sea state (0–9). Conditions remain with their entry, appear alongside notes, and are included in CSV/print, backup/sync, enrichment imports and AI drafting. New observations start blank; calm zero values survive saving and editing.

Sea-state labels follow [WMO code table 3700](https://www.nodc.noaa.gov/gtspp/document/codetbls/wmocodes/table3700.html).

This candidate completes the requested feature scope for 1.4.0.
